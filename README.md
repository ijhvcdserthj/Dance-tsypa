# Dance-tsypa

🐱 Dance Tsypa: Танцевальная ритм-игра с цыплятами

🎮 О проекте

Dance Tsypa — это ритм-игра, в которой нужно нажимать клавиши в такт музыке. На экран сверху падают стрелочки (вверх, вниз, влево, вправо). Задача игрока — нажать нужную клавишу в момент, когда летящая стрелка совпадает с зоной детектора в нижней части экрана.

Игра разработана в рамках учебной практики ГУАП (Санкт-Петербургский государственный университет аэрокосмического приборостроения).

✨ Особенности

- 🎵 **Три уровня сложности** с разной музыкой:

  - Балет (классическая музыка) — лёгкий уровень

  - Toxic (Britney Spears) — средний уровень

  - Beat It (Michael Jackson) — сложный уровень

  

- 👘 **Уникальные костюмы котиков** для каждого уровня:

  - Балетные пачки

  - Костюмы в стиле Toxic

  - Рок-образы

- 🎮 **Два режима игры**:

  - Соло (один игрок)

  - Два игрока (PvP на одной клавиатуре)

- 🐱 **Анимированные персонажи**:

  - Танец при успешном попадании

  - Грусть при промахе

🎮 Управление

1 игрок:

W - вверх

A - влево

S - вниз

D - вправо

2 игрок:

Стрелка вверх - вверх

Стрелка влево - влево

Стрелка вниз - вниз

Стрелка вправо - вправо
